# What is this?
This is simplistic automation code to help extract and run the weekly lab tester files students submit accelerating the time it takes to fulfill my duties as a TA for the IS1704 SMU Course

# How to use it?
Step 1: Download the zip file into the same directory of main.py

Step 2: Run ```python main.py``` to extract, automatically deal with nested folders, and run test files

Step 3: After visually confirmed run ```python clean.py``` to remove the zip file and the extracted folder
